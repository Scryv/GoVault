Whats under the hood



Go (Golang)

Go is an open-source programming language designed by Google to build reliable, and highly efficient software applications.

SQLite

SQLite is a lightweight, self-contained database engine that stores data in a single file, making it fast and very easy to use.

AES + SHA-512

AES handles strong data encryption, while SHA-512 creates unique cryptographic hashes to ensure data integrity and security.

HTMX

HTMX allows you to access modern browser features directly in HTML, giving you WebSockets without writing complex JavaScript.
